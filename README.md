# youtube_downloader
YouTube video downloader in the specified quality

Before compiling the programme, you need to install the "yt_dlp" and "static_ffmpeg libraries": 
pip install yt-dlp static-ffmpeg
and fill in the information in the version_file.txt file

The compiled EXE file can be downloaded from the directory https://drive.google.com/drive/folders/15cxBq0DnV9YM0oVRLJHmoxLQwW0dy4Wr?usp=sharing

The programme was written using Gemini AI

New features in version 8.1:
- the ability to cancel an operation at any stage
- saving settings to the Windows Registry: HKEY_CURRENT_USER\Software\YouTubeDownloader (does not require administrator rights)
